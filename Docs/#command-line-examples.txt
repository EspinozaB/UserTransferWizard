User State Migration Tool

Export Single Profile (to external USB):
.\scanstate "d:\USMT Profiles\[username]" /i:migapp.xml /i:miguser.xml /v:13 /ue:* /ui:contoso\[username]

Export Single Profile - OneDrive Exclusion - (to external USB):
.\scanstate "d:\USMT Profiles\[username]" /i:migapp.xml /i:miguser.xml /i:ExcludeOneDriveFolders.xml /v:13 /ue:* /ui:contoso\[username]

Import Single Profile (from external USB):
.\loadstate "d:\USMT Profiles\[username]" /i:migapp.xml /i:miguser.xml /v:13 /ue:* /ui:contoso\[username] /c

Export All Profiles (to external USB)
.\scanstate "d:\USMT Profiles\[oldcomputername]" /i:migapp.xml /i:miguser.xml /v:13 /ui:CONTOSO\* /ui:%computername%\*

Import All Profiles (to external USB)
.\loadstate "d:\USMT Profiles\[oldcomputername]" /i:migapp.xml /i:miguser.xml /v:13 /ui:CONTOSO\* /ui:%computername%\* /c
